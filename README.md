Wegalvanize.com is the former web home of Galvanize, the governance, risk, and compliance (GRC) software company behind the HighBond platform; Galvanize was acquired by Diligent and wegalvanize.com now redirects to diligent.com. The HighBond platform (audit, risk, controls, compliance, data analytics, and Robots automation) exposes a substantial public REST API built on the JSON:API v1.0 specification, documented at docs-apis.highbond.com and authenticated with OAuth 2.0 bearer tokens issued through Launchpad. This profile was seeded as a Norwest Venture Partners portfolio lead and has been enriched from the live HighBond OpenAPI (390 operations across 67 resource groups) and the provider's public identity/security surface.

**Areas:** Company · Governance · Risk Management · Compliance · Audit · GRC · Analytics · Automation · Security

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Wegalvanize: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.

- **A new API, or one that is not in the catalog yet** — [submit it on APIs.io](https://apis.io/add/).
- **Anything else** — [the APIs.io inbox](https://github.com/api-search/inbox/issues/new) or [info@apievangelist.com](mailto:info@apievangelist.com).
